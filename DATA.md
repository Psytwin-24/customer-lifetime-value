# Data

**UCI Online Retail II**

- Rows: UK subset of 1,067,371 transactions, Dec 2009 to Dec 2011
- Source: https://archive.ics.uci.edu/dataset/502/online+retail+ii
- Licence: CC BY 4.0
- 5,350 customers, 71 percent repeat buyers, average order value 435.

Raw files are **not committed**. Drop the file into `data/` under the name the
script expects, or point a symlink there, then run `python src/main.py`.
